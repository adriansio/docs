## Quick Start

### Embed the Widget

```html
<div data-storerocket="YOUR_PROJECT_ID" style="height: 600px;"></div>
<script src="https://cdn.storerocket.io/widget.js" async></script>
```

### API Request

```bash
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations" \
  -H "X-API-Key: your_api_key"
```
