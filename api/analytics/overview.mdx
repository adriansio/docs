Access analytics data for your store locator widget.

<Note>
  Analytics API is coming soon. Currently, analytics are available in the dashboard under **Analytics**.
</Note>

## Dashboard Analytics

The StoreRocket dashboard provides comprehensive analytics:

### Overview Metrics
- Total widget loads
- Search queries
- Location clicks
- Directions requests

### Geographic Data
- Searches by region
- Search heatmap
- Coverage analysis

### Location Performance
- Views per location
- Clicks per location
- Direction requests per location

### Search Intelligence
- Popular search terms
- Zero-result searches (expansion opportunities)
- Search patterns over time

Go to **Dashboard → Analytics** to view your data.

## Upcoming API Endpoints

The following endpoints will be available soon:

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v2/projects/{id}/analytics/overview` | Summary metrics |
| `GET` | `/api/v2/projects/{id}/analytics/searches` | Search analytics |
| `GET` | `/api/v2/projects/{id}/analytics/locations` | Per-location metrics |
| `GET` | `/api/v2/projects/{id}/analytics/geographic` | Geographic data |

### Planned Query Parameters

| Parameter | Description |
|-----------|-------------|
| `start_date` | Start of date range (ISO 8601) |
| `end_date` | End of date range (ISO 8601) |
| `granularity` | `day`, `week`, or `month` |
| `timezone` | Timezone for date grouping |

## Export Data

For now, you can export analytics data as CSV from the dashboard:

1. Go to **Dashboard → Analytics**
2. Select your date range
3. Click **Export** (top right)
4. Choose CSV format

[Contact us](mailto:support@storerocket.io) if you need API access sooner.
