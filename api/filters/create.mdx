## Creating Filters via Locations

The recommended way to create filters programmatically is to include them when creating locations:

```bash
curl -X POST "https://api.storerocket.io/api/v2/projects/{project_id}/locations" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Example Store",
    "address_line_1": "123 Main St",
    "city": "Seattle",
    "filters": "My New Filter, Another Filter"
  }'
```

Filters are automatically created if they don't exist, with:
- **Name:** As provided
- **Slug:** Auto-generated from name (lowercase, hyphens)
