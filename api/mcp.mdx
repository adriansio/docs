---
title: 'Connect an AI assistant (MCP)'
description: 'Let Claude Code, Cursor and other MCP clients work on your locations and analytics with your API token.'
---

StoreRocket runs a remote [Model Context Protocol](https://modelcontextprotocol.io) server. An AI assistant connected to it can put your store locator on a website, add and update locations, and read your locator's analytics, using the same API token and permissions as the REST API.

| | |
| --- | --- |
| Server URL | `https://storerocket.io/mcp` |
| Transport | Streamable HTTP |
| Authentication | `Authorization: Bearer YOUR_TOKEN` |

## Create a token

Open [API Tokens](https://storerocket.io/app/account/api-tokens) and create a token for your assistant. Tick what it may do:

| Permission | Lets the assistant |
| --- | --- |
| `location:read` | List and read locations and filters, get the install code |
| `location:create` | Add locations |
| `location:update` | Change locations |
| `location:delete` | Delete locations, one per call |
| `analytics:read` | Read analytics: views, searches, searches that found nothing, clicks, leads |

The token reaches the projects your user account belongs to, on a plan that includes the REST API. Revoke it from the same page at any time.

## Connect your client

<CodeGroup>

```bash Claude Code
claude mcp add --transport http storerocket https://storerocket.io/mcp \
  --header "Authorization: Bearer YOUR_TOKEN"
```

```json Cursor (.cursor/mcp.json)
{
  "mcpServers": {
    "storerocket": {
      "url": "https://storerocket.io/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}
```

</CodeGroup>

Any MCP client that can send an `Authorization` header to a Streamable HTTP server can connect the same way. Keep the token out of shared repositories: in Cursor, use a user-level `~/.cursor/mcp.json`.

<Note>
Connectors added inside ChatGPT or the Claude apps sign in with OAuth instead of a pasted token. StoreRocket does not offer that sign-in yet.
</Note>

## Tools

Start with `list-projects`: every other tool takes a project `id` from it.

| Tool | What it does | Permission |
| --- | --- | --- |
| `list-projects` | Your projects (store locators): id, name, location count, status, plan | none |
| `get-install-code` | The code that puts the locator on a website, with placement steps | `location:read` |
| `list-locations` | Locations, up to 100 per page, filtered by name, city, state, country or postal code | `location:read` |
| `get-location` | One location with hours, filters, custom fields and buttons | `location:read` |
| `list-filters` | Filter (category) names, with how many locations carry each | `location:read` |
| `create-locations` | Add up to 50 locations; each is saved on its own and the answer lists created and refused | `location:create` |
| `update-location` | Change only the fields sent, as [PATCH](/api/locations/update) does; `null` clears a field | `location:update` |
| `delete-location` | Delete one location, permanently | `location:delete` |
| `get-analytics-overview` | Views, searches, searches with no results, clicks and leads for a date range, with the period before | `analytics:read` |
| `get-top-searches` | The most searched places and words, with how many found nothing | `analytics:read` |
| `get-searches-with-no-results` | Where visitors searched and found no location nearby | `analytics:read` |
| `get-most-clicked-locations` | The most clicked locations, by kind of click (directions, calls, website, buttons) | `analytics:read` |

Location tools call the [REST API](/api/introduction): the same validation, geocoding and error messages. Analytics tools return the same numbers as Analytics in the dashboard. Dates are `YYYY-MM-DD` in UTC, up to 366 days per request, 30 days by default. Analytics count what visitors did on the locator, not sales or store visits.

## Limits and errors

- Requests share your REST API rate limit. Analytics tools also allow 30 requests a minute per person.
- A refused call returns an MCP tool error with the reason, such as a missing permission, a plan without API access, or a project id that is not in your account. Another account's projects and locations are never returned.
- `create-locations` without coordinates looks each address up while the request waits. For hundreds of rows, use an import or [Google Sheets sync](https://help.storerocket.io) in the dashboard.
