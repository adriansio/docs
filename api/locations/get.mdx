---
title: 'Get Location'
description: 'Retrieve a single location'
api: 'GET /api/v2/projects/{project_id}/locations/{location_id}'
---

Returns details for a specific location.

## Request

```bash
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations/{location_id}" \
  -H "X-API-Key: your_api_key"
```

## Path Parameters

<ParamField path="project_id" type="string" required>
  Your project's hashid.
</ParamField>

<ParamField path="location_id" type="string" required>
  The location's hashid.
</ParamField>

## Query Parameters

<ParamField query="includeFilters" type="boolean" default="false">
  Include filter associations.
</ParamField>

<ParamField query="includeFields" type="boolean" default="false">
  Include custom field values.
</ParamField>

<ParamField query="includeHours" type="boolean" default="false">
  Include business hours.
</ParamField>

<ParamField query="includeCallsToAction" type="boolean" default="false">
  Include CTA button values.
</ParamField>
