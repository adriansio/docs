---
title: 'List Locations'
description: 'Retrieve all locations for a project'
api: 'GET /api/v2/projects/{project_id}/locations'
---

Returns a paginated list of locations.

## Request

```bash
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations" \
  -H "X-API-Key: your_api_key"
```

## Path Parameters

<ParamField path="project_id" type="string" required>
  Your project's hashid.
</ParamField>

## Query Parameters

<ParamField query="limit" type="integer" default="15">
  Results per page (max 100).
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number.
</ParamField>

<ParamField query="includeFilters" type="boolean" default="false">
  Include filter associations.
</ParamField>

<ParamField query="includeFields" type="boolean" default="false">
  Include custom field values.
</ParamField>

<ParamField query="includeHours" type="boolean" default="false">
  Include business hours.
</ParamField>

<ParamField query="includeCallsToAction" type="boolean" default="false">
  Include CTA button values.
</ParamField>

### Filtering

Filter locations by field values:

| Parameter | Description | Example |
|-----------|-------------|---------|
| `city` | Filter by city | `?city=Seattle` |
| `state` | Filter by state | `?state=WA` |
| `country` | Filter by country | `?country=US` |
| `postcode` | Filter by postal code | `?postcode=98101` |
| `visible` | Filter by visibility | `?visible=true` |

## Examples

### Get all locations with filters and hours

```bash
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations?includeFilters=true&includeHours=true&limit=50" \
  -H "X-API-Key: your_api_key"
```

### Filter by city

```bash
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations?city=Seattle" \
  -H "X-API-Key: your_api_key"
```

### Pagination

```bash
# Get page 2 with 25 results per page
curl -X GET "https://api.storerocket.io/api/v2/projects/{project_id}/locations?page=2&limit=25" \
  -H "X-API-Key: your_api_key"
```
