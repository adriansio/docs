---
title: 'Delete a location'
description: 'Remove a location from a project.'
api: 'DELETE /api/v2/projects/{project_id}/locations/{location_id}'
---

Requires `location:delete` and project API access. The location must belong to the project in the URL.

<ParamField path="project_id" type="string" required>The public project ID.</ParamField>
<ParamField path="location_id" type="string" required>The public location ID.</ParamField>

<RequestExample>
```bash
curl -X DELETE 'https://storerocket.io/api/v2/projects/PROJECT_ID/locations/LOCATION_ID' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Accept: application/json'
```
</RequestExample>

<ResponseExample>
```json
{"success":true}
```
</ResponseExample>

A successful deletion returns `200`. The location is removed from the project and its widget results.
Errors: `401` authentication, `403` access/permission, `404` inaccessible project or location, `429` rate limit. See [errors](/api/errors).
