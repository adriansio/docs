---
title: 'Create Location'
description: 'Add a new location'
api: 'POST /api/v2/projects/{project_id}/locations'
---

Creates a new location and returns the created resource.

## Request

```bash
curl -X POST "https://api.storerocket.io/api/v2/projects/{project_id}/locations" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Downtown Seattle",
    "address_line_1": "123 Main St",
    "city": "Seattle",
    "state": "WA",
    "postcode": "98101",
    "country": "US",
    "phone": "(206) 555-1234"
  }'
```

## Path Parameters

<ParamField path="project_id" type="string" required>
  Your project's hashid.
</ParamField>
