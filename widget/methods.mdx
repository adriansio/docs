After the widget starts, you can call methods on it from your own page.

## Getting the Widget Instance

```js
const widget = await StoreRocket.create({
  account: 'abc123',
  container: '#locator'
});

widget.search('New York');
```

You can also fetch an instance that already started, for example one created from a `data-storerocket` element:

```js
const widget = StoreRocket.get('#locator'); // null if there is none
```

Other helpers on the global `StoreRocket` object: `StoreRocket.destroy(container)`, `StoreRocket.destroyAll()`, `StoreRocket.scan()`, `StoreRocket.watch()` and `StoreRocket.unwatch()`.

<Note>
  Only the methods on this page exist on a widget. Anything else (for example `setFilters` or `getVisibleLocations`) is not available and will throw `is not a function`.
</Note>

---

## Search

### search(query, center?)

Run a search. `query` is the text shown for the search (an address, zip code or city). `center` is the point to search around.

```js
widget.search('New York', { lat: 40.7128, lng: -74.0060 });
```

Returns a Promise that resolves when the results are ready and rejects if the search fails.

<ParamField path="query" type="string">
  The search text.
</ParamField>

<ParamField path="center" type="{ lat: number, lng: number }">
  The coordinates to search around.
</ParamField>

### clearSearch()

Clear the search and reset the results.

```js
widget.clearSearch();
```

## Locations

### getLocations()

Returns the locations the widget currently has loaded.

```js
const locations = widget.getLocations();
console.log(`Loaded: ${locations.length}`);
```

### selectLocation(id)

Open a location, as if the visitor had clicked it. Returns a Promise.

```js
widget.selectLocation('abc123');
```

<ParamField path="id" type="string">
  The location ID. It must be one of the locations the widget has loaded.
</ParamField>

### getSelectedLocation()

Returns the open location, or `null`.

```js
const selected = widget.getSelectedLocation();
```

### addLocation(data) and removeLocation(id)

Add or remove a location in the widget on this page only. Nothing is saved to your StoreRocket account.

```js
widget.addLocation({ name: 'Pop-up shop', lat: 40.7128, lng: -74.0060 });
widget.removeLocation('abc123');
```

## State

### getState()

Returns the widget's current state. The filters the visitor has switched on are at `filters.active`.

```js
const { filters } = widget.getState();
console.log(filters.active);
```

## Map

### setCenter(lat, lng)

Move the map to a point.

```js
widget.setCenter(40.7128, -74.0060);
```

### setZoom(zoom)

Set the map zoom level.

```js
widget.setZoom(12);
```

### fitToLocations(locations, options?)

Fit the map around a list of locations.

```js
widget.fitToLocations(widget.getLocations());
```

## Look

### getTheme() and setTheme(slug)

Read or change the theme. `setTheme` returns a Promise.

```js
widget.getTheme();          // 'aurora'
await widget.setTheme('aurora');
```

### setDarkMode(enabled)

```js
widget.setDarkMode(true);
```

### setBrandColor(hue, saturation?)

```js
widget.setBrandColor(210, 91);
```

### setBorderRadius(preset)

Set the corner rounding: `'sharp'`, `'rounded'` or `'pill'`.

```js
widget.setBorderRadius('pill');
```

## Events

### on(event, handler)

Listen to an event. Returns a function that stops listening.

```js
const stop = widget.on('select', (location) => {
  console.log('Selected:', location.name);
});

// Later
stop();
```

### off(event, handler)

Stop listening to an event.

```js
const handler = (location) => console.log(location);
widget.on('select', handler);
widget.off('select', handler);
```

### Available events

| Event | Handler receives |
|---|---|
| `ready` | the widget |
| `search` | `(query, results)` |
| `select` | the location |
| `filtersChange` | the list of active filters |
| `error` | the error |
| `analytics` | `{ event, timestamp, projectId, ... }` |

The widget also fires browser events on its container element. They bubble, so you can listen on `document`:

| Browser event | `event.detail` |
|---|---|
| `storerocket:ready` | `{ widget }` |
| `storerocket:search` | `{ query, results, center }` |
| `storerocket:location-view` | `{ location }` |
| `storerocket:filter-change` | `{ filters }` |
| `storerocket:radius-change` | `{ radius, unit }` |
| `storerocket:units-change` | `{ unit }` |
| `storerocket:show-all` | `{ count }` |

```js
document.addEventListener('storerocket:location-view', (e) => {
  console.log('Viewed:', e.detail.location.name);
});
```

## Lifecycle

### destroy()

Remove the widget and clean up everything it added.

```js
widget.destroy();
```

<Warning>
  After `destroy()` the instance is no longer usable. Create a new one if you need the widget again.
</Warning>

## Example: External Search Form

Run searches from your own form:

```html
<form id="store-search">
  <input type="text" name="location" placeholder="Enter city or zip">
  <button type="submit">Find Stores</button>
</form>

<div id="locator" style="height: 600px;"></div>

<script>
  let widget;

  StoreRocket.create({
    account: 'abc123',
    container: '#locator'
  }).then(w => widget = w);

  document.getElementById('store-search').addEventListener('submit', (e) => {
    e.preventDefault();
    widget.search(e.target.location.value);
  });
</script>
```

## Example: Show a Counter

Show how many filters are active outside the widget:

```html
<p>Active filters: <span id="filter-count">0</span></p>
<div id="locator" style="height: 600px;"></div>

<script>
  StoreRocket.create({
    account: 'abc123',
    container: '#locator'
  }).then(widget => {
    widget.on('filtersChange', (active) => {
      document.getElementById('filter-count').textContent = active.length;
    });
  });
</script>
```
