The StoreRocket Widget is a drop-in store locator that works on any website. It's fast, mobile-friendly, and fully customizable.

## Features

<CardGroup cols={2}>
  <Card title="Lightning Fast" icon="bolt">
    Geohash-compressed data loads instantly, even with thousands of locations.
  </Card>
  <Card title="Mobile-First" icon="mobile">
    Responsive design with native-feeling touch gestures and bottom sheets.
  </Card>
  <Card title="Smart Search" icon="magnifying-glass">
    Autocomplete with address suggestions and location name matching.
  </Card>
  <Card title="Clustering" icon="layer-group">
    Automatically groups nearby markers for clean maps at any zoom level.
  </Card>
</CardGroup>

## Quick Example

Add this to your HTML:

```html
<div data-storerocket="YOUR_PROJECT_ID" style="height: 600px;"></div>
<script src="https://cdn.storerocket.io/widget.js" async></script>
```

That's it. The widget loads your locations and renders a fully functional store locator.

## Map Providers

StoreRocket supports both **Google Maps** and **Mapbox**. Configure your preferred provider in the dashboard, or override it per-embed.

## Themes

Four built-in themes to match your brand:

| Theme | Description |
|-------|-------------|
| `aurora` | Modern, clean design with purple accents (default) |
| `nebula` | Dark mode with vibrant gradients |
| `eclipse` | Minimal, high-contrast design |
| `starter` | Basic theme for maximum customization |
