---

The widget supports 38 languages out of the box and auto-detects the user's browser language.

## Setting Language

### Via Data Attribute

```html
<div data-storerocket="abc123" data-language="es"></div>
```

### Via JavaScript

```js
StoreRocket.create({
  account: 'abc123',
  container: '#locator',
  language: 'es'
});
```

## Auto-Detection

By default (`language: null`), the widget detects language from:

1. `navigator.language` (browser setting)
2. `<html lang="...">` attribute
3. Falls back to `en` (English)

---

## RTL Support

Arabic, Hebrew, Persian, and other RTL languages are automatically supported. The widget layout mirrors for RTL locales.

---

## Custom Strings

Override specific strings in the dashboard under **Widget → Translations**, or contact support for custom translations.

---

## Per-Page Language

Use different languages on different pages:

```html
<!-- English page -->
<div data-storerocket="abc123" data-language="en"></div>

<!-- Spanish page -->
<div data-storerocket="abc123" data-language="es"></div>
```

---

## Distance Units

Language and distance units are independent:

```js
StoreRocket.create({
  account: 'abc123',
  container: '#locator',
  language: 'en',        // English UI
  search: {
    unit: 'kilometers'   // But use kilometers
  }
});
```
